# 🟢 AI-SENTINEL // COMMAND_CENTER

A futuristic, cyber-themed AI interface built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**. This project demonstrates advanced frontend styling (Matrix-Rain Canvas) and secure backend communication via Server Actions.

## ⚡ Tech Stack
* **Framework**: Next.js 15 (App Router)
* **Language**: TypeScript
* **Styling**: Tailwind CSS (Custom Cyberpunk Theme)
* **Animations**: HTML5 Canvas (Digital Rain Effect)
* **Backend**: Next.js Server Actions for secure API communication

## 🚀 Key Features
* **Interactive Terminal**: A custom-built UI that mimics a high-end hacker workstation.
* **Matrix Background**: A high-performance digital rain effect rendered on a 2D Canvas.
* **Fullstack Integration**: Securely handles API requests without exposing sensitive keys to the client.
* **Responsive Design**: Fully optimized for various screen sizes with a focus on dark-mode aesthetics.

## 🛠️ Installation & Setup
1. Clone the repository:
   ``` 
   git clone [https://github.com/junesdream/ai-sentinel.git](https://github.com/junesdream/ai-sentinel.git) 
   ```
2. Install dependencies:
    ```
    npm install
    ````
3. Environment Variables: Create a .env.local file and add your API credentials:
    ```
    GOOGLE_AI_KEY=your_api_key_here
    ```
4. Run the development server: 
    ```
    npm run dev
    ```
